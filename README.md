# Blockflow

A concept case study and clickable prototype: plan, make and price AI campaigns as visible flows of building blocks.

**Plan the canvas before you paint.** Instead of a single prompt box, Blockflow lays the creative process out on screen:

- **Across: the steps.** Blocks (Moodboard, Prompt, Image, Upscale, Video, Sound) connect from the first idea to a finished campaign deck.
- **Down: the alternatives.** Remix a flow to try another direction. Flows stack, so a team can compare whole ideas and pick one.
- **Price first.** Every step shows its price before it runs, and one credit jar shows the project budget.
- **Check first.** A short check catches wrong settings, like a video format that doesn't match the brief, before an expensive step.

All images are flower placeholders and all prices are sample values.

## Try it

Open `index.html` in a browser. It is a single self-contained page; React and htm load from a CDN.

To publish it with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## What you can do

- Take the 3-step quick start, or the full tour from the settings menu.
- Tap any image to open it big: zoom in, flip through the set, ♥ the keepers, compare upscales before and after.
- Add blocks by tapping, dragging onto a string, or with the + on any string.
- Change models, versions and video format, and watch the price change before you run.
- Upload your own reference photos into the moodboard.
- Write a prompt that changes the next result.
- Play the Reel and the soundtrack (generated live in the browser).
- Play with the price per block, remix flows, vote, and pick a team flow.
